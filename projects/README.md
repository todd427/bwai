# Projects

This directory holds your weekly projects. Use the CLI to scaffold them:

```bash
bwai new-project my-project --week 1
```

Structure after a few weeks:

```
projects/
├── week1-thinking-with-ai/
│   └── hello-claude/
├── week2-ai-augmented-coding/
│   └── code-review-tool/
├── week3-ai-powered-features/
│   └── writing-assistant/
├── week4-rag-and-knowledge/
│   └── course-qa-bot/
├── week5-agents-and-automation/
│   └── research-agent/
└── week6-portfolio-and-next/
    └── final-reflection/
```
